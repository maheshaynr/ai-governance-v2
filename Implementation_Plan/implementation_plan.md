## 1. Advanced Architecture Flow (The Egress Shield)

1.  **Frontend Chat Interface:** A thin client UI that makes requests.
2.  **Backend Governance API (The Shield):**
    *   **The Orchestrator:** Receives requests and queries the appropriate backend system (either an SQL Database or an internal AI model).
    *   **The Checksum Engine:** `custom_recognizers.py` contains advanced mathematical validation (Verhoeff algorithm) for Aadhaar and context-scoring logic to eliminate false positives.
    *   **The Universal PII Guardrail:** A single, shared masking function runs *before* any data (whether from an SQL DB or generated by an AI) is sent back to the Frontend. This shared code path prevents drift.
3.  **Secure Audit Logging:** `governance_audit.json` securely logs transactions. *Note: To ensure strict compliance (Data Minimization), the raw unmasked text is NEVER logged in plaintext. It is either omitted or cryptographically hashed, while the masked string is logged for proof.*

## 2. Advanced PoC Test Cases (Success Criteria)

### Test Case 1: The False Positive (Proving Context & Math)
*   **The Scenario:** A user types a 12-digit order number that looks like an Aadhaar but fails the math.
*   **Input:** "Cancel order number 9999 4105 7059." *(Note: The 12th digit '9' fails the Verhoeff checksum. A valid checksum for this sequence is '8').*
*   **Governed Output (Success):** "Cancel order number 9999 4105 7059." *(System correctly ignores it).*

### Test Case 2: The DB Cohort Retrieval
*   **The Scenario:** Analyst queries the database for customer data. 
*   **Simulated Backend Output:** `{"customer": "Mahesh", "phone": "9876543210", "aadhaar_valid": "9999 4105 7058"}` *(Note: '8' is mathematically verified via Verhoeff).*
*   **Governed Output (Success):** `{"customer": "<PERSON>", "phone": "<PHONE_NUMBER>", "aadhaar_valid": "<IN_AADHAAR>"}`

### Test Case 3: The AI Hallucination Shield
*   **The Scenario:** An internal AI model hallucinates or retrieves sensitive data.
*   **Simulated AI Generation:** "Please use the corporate credit card 4111-2222-3333-4444 and reference PAN Card ABCDP1234F." *(Note: 'P' structurally validates the PAN as an 'Individual').*
*   **Governed Output (Success):** "Please use the corporate credit card <CREDIT_CARD> and reference PAN Card <IN_PAN>."
